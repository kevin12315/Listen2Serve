# Complete conversation examples

Three original calls illustrate collection N/E (8 turns), marketing E/E
(10 turns), and hotline N/N (6 turns). Open [the listening page](index.html)
for full-call audio, aligned turns, critical exchanges, scenario context and
model provenance.

metadata and file fingerprints. The [offline example](../offline/README.md)
illustrates the trajectory, per-item verdict and four-metric report formats
using deterministic local services.
